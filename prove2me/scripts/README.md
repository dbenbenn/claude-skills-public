## Structural findings

**Duplication.**
- Lean declaration heads are parsed by regex in 8 scripts, and namespace/`end` stacks are kept in 8.
- Comment stripping exists in 3 versions; `_workspace()` in 3 copies (`p2m`, `prune_solution`,
  `stage_auditor`); `published()` in 2 (`build_solution`, `rewire`).

**Inverted layering.**
- `p2m` (the API client) imports `stage_auditor` (for `strip`).
- 11 scripts import `prune_solution` for `_workspace`/`parse`, not for pruning.

**Six scripts are missing from SKILL.md:** `build_solutions`, `check_pronouns`, `decisions`, `p2m`,
`publish_standalone`, `publish_status`. `watch_proposal` and `submit_all` were added only on
2026-10-02, after going unused.

**Two builders.** `build_solution` (documented, uncalled) and `build_solutions` (undocumented, used
by `submit_all`).

**Two edge auditors.** `edge_audit` (by name) and `edge_overlap` (by shared steps). Type equality
over LeanInfo subsumes both.
